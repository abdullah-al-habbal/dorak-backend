# 05 — Website Domain Glossary
> The bounded vocabulary for the public website.

- **Universe Toggle:** The UI element that switches the site's content and accent colors between Men's Grooming, Women's Beauty, or Neutral.
- **Neutral Base Theme:** The core visual identity of the site (layout, typography, base colors) that remains constant regardless of the selected universe.
- **Freemium Gate:** The visual representation on the Pricing page showing what is free (1 branch) vs. Premium (multi-branch, job board).
- **Backend-Driven UI Preview:** The interactive, read-only demo of the shop floor plan on the website, proving that the app draws what the backend describes.
- **Marketing Content:** The structured data (Pages, Sections, Testimonials) managed by the Platform Admin in the Filament panel and served to the website.
